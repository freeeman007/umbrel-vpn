# Umbrel VPN store (lii-it)

Community app store для umbrelOS 2.x:

- `vpn-az` — клиент AntiZapret для Umbrel: сплит-VPN к своему VPS, DNS для контейнеров,
  WG-сервер для доступа к Umbrel снаружи.

Добавить в Umbrel: App Store → Community App Stores → Add → `https://github.com/freeeman007/umbrel-vpn`
